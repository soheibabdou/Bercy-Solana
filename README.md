# 🦅 Bercy Solana Pay

Cross-border FX payments on Solana Mainnet via x402 + AC2 + Jupiter.

- x402 payment gate — real on-chain USDC verification
- AC2 human approval before every payment
- Jupiter DEX integration for best swap rates
- 95+ corridors: Africa, LatAm, Asia, Crypto
- $0.10 USDC per route — ~1 second settlement
